# 🤖 AI Data Quality & Cleaning Agent

> **LLM-powered data quality analysis and automated Python/Pandas code generation.**

An AI-powered application that analyzes tabular datasets, identifies data-quality issues, and generates Python/Pandas code to automate the selected cleaning operations.

The project combines **Generative AI, structured LLM outputs, Pydantic validation and automated code generation** in an interactive Streamlit application.

## 🚀 Key Features

* 📊 **Automated data profiling** — schema, missing values, duplicates, statistics and representative samples.
* 🧠 **LLM-based data quality analysis** — detects potential inconsistencies and data-quality issues.
* 📦 **Structured outputs with Pydantic** — converts LLM responses into reliable, validated objects.
* 🐍 **AI-generated code** — generates cleaning scripts based only on the issues selected by the user.
* 👤 **Human-in-the-loop** — the user reviews and validates proposed corrections before execution.
* ⚡ **Interactive Streamlit interface** — upload, analyze, review and clean datasets through a simple UI.

## 🔄 Workflow

```text
Dataset
   ↓
Data Profiling
   ↓
LLM Analysis
   ↓
Structured Pydantic Output
   ↓
User Validation
   ↓
Python/Pandas Code Generation
   ↓
Code Execution
   ↓
Clean Dataset
```
